# Troubleshooting
503 on export: kicad-cli missing. "pcbnew not available": set PCBNEW_PYTHON to an interpreter that can import pcbnew. Simulation 422: read the ngspice error (floating node, bad node name, timeout). 429: raise RATE_LIMIT_PER_MIN. KiCad/ngspice tests skip when the tools are absent (check the skip count).
