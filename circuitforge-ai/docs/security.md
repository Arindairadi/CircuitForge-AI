# Security
Implemented: argon2 password hashing; random bearer tokens stored as SHA-256 hashes, expiring (TOKEN_TTL_DAYS, default 7), revocable (logout; password change revokes all); ownership + role checks (404 for non-members, 403 for insufficient role); Pydantic validation; netlist name validation; ngspice in a temp dir with CPU/memory rlimits and timeouts; pcbnew/kicad-cli called with argument lists (no shell) and server-built paths; AI output schema-validated and never executed; whitelisted download filenames; per-user in-memory rate limit; CORS allowlist; audit log for key project actions.
Limitations: no email verification/password reset/MFA; rate limiter and jobs are per-process; rlimits are not containers (KiCad tools run unsandboxed as the server user); no HTTPS (use a reverse proxy); audit log covers create/update/delete/sharing/password only; no upload endpoints exist.

## Uploads and parts data (added)
Datasheet uploads: PDF only (magic-byte check, not the client's content type), 5 MB cap, 20 per project, stored under server-generated names (the user's filename is sanitized and display-only), never parsed or executed, served with `nosniff`, access follows project roles. Part assignments, library entries and URLs are user-entered, URL-scheme validated (http/https only) and labelled unverified. Distributor adapter: fails closed without credentials; responses parsed defensively, nothing cached. AI: per-user daily quota (AI_DAILY_LIMIT) plus the per-minute rate limit.
